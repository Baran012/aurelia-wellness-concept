# Aurelia Wellness — Concept Redesign

A responsive, single-page wellness/coaching website concept created by Baran Celik as a portfolio demonstration. This is a fictional brand and not a live business or client project.

## Preview locally

Open `index.html` in a modern browser. For the best local experience, run a simple static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Responsive desktop and mobile layouts
- Mobile navigation menu
- Anchor-based navigation and calls to action
- Expandable FAQ accordion
- Client-side demo contact form with a clear non-submission notice
- Local optimized WebP image assets
- Reduced-motion support and accessible form labels

## Important demo limitations

- Aurelia Wellness is a fictional concept brand.
- Program descriptions are illustrative. No real coaching services are offered.
- No booking, payment, CRM, email, analytics, or CMS backend is connected.
- The contact form validates in the browser but does not send or store information.
- Any implementation for a real client would require their approved content, assets, platform access, and integrations.

## Publish

This is a static site and can be deployed to Vercel, Netlify, or GitHub Pages. On Vercel, import the folder/repository and keep the framework preset as **Other**; no build command or output directory is required.

## Portfolio positioning

Present this as: **Aurelia Wellness — Independent Concept Website Redesign**.
